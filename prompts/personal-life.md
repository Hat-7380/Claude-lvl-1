# 🏠 Personal life prompts

Replace `[brackets]` with your details. See the [planning guide](../guides/planning-and-organizing.md) for tips.

---

## Organizing

### Brain dump → plan
```
Here's everything on my mind: [messy list]. Turn it into a prioritized
to-do list for this week and tell me what to do today.
```

### Weekly schedule
```
Make me a weekly schedule as a table. Fixed commitments: [list].
I want to fit in: [list]. Be realistic and don't overload me.
```

### Break down a goal
```
My goal: [goal] by [date]. Starting point: [where you are now].
Time available: [hours per week]. Break it into monthly milestones
and give me this week's tasks.
```

## Money

### Simple budget
```
I earn [amount]/month. Fixed costs: [list with amounts]. I want to save
[amount] for [goal]. Make a simple budget with categories.
```

### Understand spending
```
Here's my spending for [period]. Group it by category, show where most
money goes, and suggest 3 realistic ways to cut back.

[paste or attach]
```

### Explain a financial thing
```
Explain [loan / interest / credit score / investing / taxes] in simple
words with an example using real numbers. I'm a complete beginner.
```

## Food

### What can I cook?
```
I have: [ingredients]. I have [time] minutes. Suggest 3 simple meals
I can make. I don't eat [restrictions].
```

### Meal plan
```
Make a [number]-day meal plan for [number] people. Budget: [low/medium].
Goals: [healthy / cheap / quick / high protein]. Include a shopping list.
```

## Health & wellbeing

> ⚠️ Claude is not a doctor. Use these to understand and prepare, not to diagnose.

### Prepare for a doctor visit
```
I'm seeing a doctor about [symptoms/issue]. Help me prepare: what
information should I bring, and what questions should I ask?
```

### Understand medical words
```
My doctor/test result says [term or result]. Explain what this means
in simple words. What questions should I ask my doctor about it?
```

### Start a habit
```
I want to start [exercise / reading / sleeping earlier / etc.].
I've failed before because [reason]. Give me a very small, realistic
plan for the first 2 weeks.
```

## Decisions & relationships

### Help me decide
```
I'm choosing between [A] and [B]. My situation: [details]. What matters
to me: [list]. Don't decide for me. Help me think: pros, cons, what I
might be missing, and questions to ask myself.
```

### Gift ideas
```
Gift ideas for my [person], who is [age] and likes [interests].
Budget: [amount]. Give 10 ideas, from practical to creative.
```

### Hard conversation
```
I need to talk to my [family member / partner / friend] about [issue].
I want to [goal] without a fight. Help me plan what to say and how
to stay calm.
```

## Home & travel

### Trip plan
```
Plan a [number]-day trip to [place] for [who]. Budget: [level].
We like [interests]. We don't like [dislikes]. Day-by-day with rough costs.
```

### Packing list
```
Make a packing list for [number] days in [place] in [month].
Activities: [list]. Traveling with [carry-on only / checked bag].
```

### Fix something at home
```
[Describe the problem, or attach a photo.] What could be causing this?
Can I fix it myself safely, or should I call a professional?
```
