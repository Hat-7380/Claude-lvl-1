# 🎨 Creative prompts

For fun, ideas, and getting unstuck. Replace `[brackets]` with your details.

---

### Brainstorm anything
```
Give me 20 ideas for [thing]. Make the first 10 normal and practical,
and the last 10 unusual and creative. No explanations, just the list.
```

### Pick the best idea
```
Here are my ideas: [list]. Which 3 are the strongest and why?
What would make each one even better?
```

### Name something
```
Suggest 20 names for my [business / project / channel / pet].
It's about [description]. The feeling I want: [e.g. modern, friendly,
serious]. Short and easy to remember.
```

### Bedtime story
```
Write a 5-minute bedtime story for a [age]-year-old who loves [things].
Make the main character named [name]. Gentle ending, with a small lesson
about [value].
```

### Write a poem or card
```
Write a short [birthday / wedding / thank-you] message for [person].
Things about them: [details]. Tone: [funny / warm / emotional].
Give me 3 options.
```

### Speech or toast
```
Write a [number]-minute toast for [event] about [person]. Include this
story: [short story]. Funny but kind. Easy to say out loud.
```

### Story together
```
Let's write a story together. Genre: [fantasy / mystery / sci-fi].
You write one paragraph, then stop and give me 3 choices for what
happens next. I'll choose.
```

### Play a game
```
Let's play 20 questions. You think of [an animal / a famous person /
an object], and I'll guess.
```

```
Be a text adventure game. I'm in [setting]. Describe where I am and
let me type what I do.
```

### Debate me
```
I believe [opinion]. Argue the opposite side as strongly as you can,
so I can test my thinking. Be respectful but don't go easy on me.
```

### Get unstuck creatively
```
I'm stuck on [project]. Ask me 5 questions that might help me see it
differently. Then suggest 3 unexpected directions I could try.
```

### Make it fun
```
Explain [boring topic] as if you were [a sports commentator / a pirate /
a dramatic movie trailer narrator].
```

### Party planning
```
Give me ideas for a [theme] party for [who, how many people].
Include decorations, food, games, and music, on a [budget] budget.
```
