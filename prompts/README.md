# Prompts

Copy-paste prompts you can use right away.

## How to use

1. Find a prompt you like
2. Copy it (on GitHub, hover over the box and click the 📋 copy button)
3. Replace everything in `[square brackets]` with your own details
4. Paste into Claude and send
5. Ask for changes until it's right

> 💡 These are starting points, not magic spells. The more of **your** details you add, the better the result. See [How to ask well](../start-here/04-how-to-ask-well.md).

## ⭐ The 5 most useful prompts

If you only save five, save these.

**1. The "ask me first" prompt** (use it for anything complicated)
```
I want help with [task]. Before you start, ask me the questions
you need answered to do this really well. Ask them all at once.
```

**2. The honest feedback prompt**
```
Give me honest, direct feedback on this. What's weak? What would
an expert criticize? Don't be polite, be useful.

"""
[paste your work]
"""
```

**3. The explain-simply prompt**
```
Explain [topic] in simple words, like I'm 14. Use one everyday
example. Then tell me the one thing most people get wrong about it.
```

**4. The polish-but-keep-my-voice prompt**
```
Fix the grammar and make this sound natural, but keep my words
and style. Don't make it longer or more formal.

"""
[paste your text]
"""
```

**5. The summary-for-a-new-chat prompt**
```
Summarize this conversation so I can paste it into a new chat
and continue. Include the key decisions, what's done, and what's next.
```
