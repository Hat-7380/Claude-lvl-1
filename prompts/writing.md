# ✍️ Writing prompts

Replace `[brackets]` with your details. See the full [writing guide](../guides/writing-emails-and-messages.md) for tips.

---

### Write an email
```
Write an email to [who] about [what]. Context: [background].
I want them to [desired result]. Tone: [polite / friendly / firm / formal].
Keep it under [number] words.
```

### Reply to an email
```
Here's an email I received:

"""
[paste email]
"""

Write a reply that says [your main point]. Tone: [tone]. Keep it short.
```

### Fix grammar but keep my voice
```
Fix grammar and spelling and make this sound natural. Keep my words
and style as much as possible. Don't make it longer. After, list
the main mistakes so I can learn from them.

"""
[paste text]
"""
```

### Change the tone
```
Rewrite this to sound more [polite / confident / warm / professional /
casual]. Keep the meaning the same.

"""
[paste text]
"""
```

### Make it shorter
```
Cut this to half the length without losing the important points.

"""
[paste text]
"""
```

### Say no politely
```
Help me say no to [request] from [person, e.g. my boss / a friend].
Reason: [your reason, or "I don't want to give a reason"].
I want to stay on good terms. Write a short message.
```

### Follow up when nobody replies
```
I sent [what] to [who] [how long] ago and got no reply. Write a short,
polite follow-up that doesn't sound annoyed.
```

### Write a complaint that gets results
```
Write a complaint to [company] about [problem]. What happened: [details,
dates, order number]. I want [refund / replacement / apology / fix].
Be firm and clear, not angry.
```

### Apologize
```
Help me apologize to [who] for [what happened]. I want to take
responsibility without over-explaining or making excuses. Keep it sincere
and short.
```

### Social media post
```
Write a [LinkedIn / Instagram / Telegram] post about [topic or news].
Audience: [who follows you]. Tone: [tone]. Length: [short / medium].
Give me 3 versions. No hashtag spam, max 3 hashtags.
```

### Translate naturally
```
Translate this into [language]. Make it sound natural, like a native
speaker wrote it, not word-for-word. It's for [context, e.g. a formal
letter / a text to a friend].

"""
[paste text]
"""
```

### Make writing sound less like AI
```
This sounds too much like AI. Rewrite it to sound like a normal person
wrote it: simpler words, shorter sentences, no fancy phrases like
"delve", "moreover", or "in today's fast-paced world".

"""
[paste text]
"""
```
