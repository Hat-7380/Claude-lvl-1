# 💼 Work prompts

Replace `[brackets]` with your details. See the full [job search guide](../guides/job-search.md) for tips.

---

## Job search

### Review my CV
```
Review my CV for [job title] roles like a recruiter with 30 seconds per CV.
What's the first thing you'd change? What's missing? Be direct.

"""
[paste CV]
"""
```

### Tailor CV to a job
```
Compare my CV to this job posting. What matches? What keywords am I
missing? Suggest changes, but never add anything that isn't true.

JOB: """[paste posting]"""
CV: """[paste CV]"""
```

### Cover letter
```
Write a cover letter for [job] at [company] based on my CV. Under 250
words. Sound human, not like a template. No clichés.

"""[paste CV]"""
```

### Mock interview
```
Be an interviewer for a [job title] role. Ask one question at a time.
After each of my answers, give short feedback and a stronger example
answer. Start now.
```

### Salary negotiation
```
I got an offer for [job] at [salary]. I want [target]. My reasons:
[experience, other offers, market rate]. Write a polite, confident
message to negotiate.
```

## Everyday work

### Meeting notes → action items
```
Turn these meeting notes into: a 3-line summary, a list of decisions,
and action items with who's responsible and the deadline.

"""
[paste notes]
"""
```

### Prepare for a meeting
```
I have a meeting with [who] about [topic]. My goal is [goal].
Help me prepare: key points to make, questions they might ask,
and how to answer them.
```

### Write a report
```
Write a short report on [topic] for [audience, e.g. my manager].
Include: summary, key findings, and recommendations. Here's my info:

[paste data or notes]
```

### Explain something to my boss
```
Help me explain [technical thing / problem] to my manager, who isn't
technical. Short, clear, and focused on what it means for the business.
```

### Ask for a raise
```
Help me prepare to ask for a raise. My role: [role]. Time there: [time].
Achievements: [list]. Write talking points, not a script.
```

### Prioritize my tasks
```
Here are my tasks: [list]. Deadlines: [list]. Help me prioritize them
using urgent vs important. What should I do first, and what can I delay
or delegate?
```

### Write a presentation outline
```
Create an outline for a [number]-minute presentation on [topic] for
[audience]. Include the main message, sections, and one strong opening line.
```

### Excel / Google Sheets formula
```
I need a [Excel / Google Sheets] formula that [describe what you want].
My data is in columns [describe]. Explain how it works.
```

### Difficult conversation at work
```
I need to talk to [coworker / employee / manager] about [issue].
I want to [goal] without making it personal. Help me plan what to say
and how to respond if they get defensive.
```
