# 📚 Learning prompts

Replace `[brackets]` with your details. See the full [studying guide](../guides/studying-and-learning.md) for tips.

---

### Explain a topic simply
```
Explain [topic] to me. My level: [beginner / high school / university].
Use simple words and one real-life example. Then check my understanding
with one question.
```

### Explain it 3 ways
```
Explain [topic] in three different ways: an analogy, a step-by-step
explanation, and a real-world example.
```

### Quiz me
```
Quiz me on [topic], 10 questions, one at a time. Wait for my answer
before asking the next. Tell me if I'm right and explain if I'm wrong.
At the end, tell me what to review.
```

### Turn notes into flashcards
```
Turn these notes into [number] flashcards. Format each one as:
Q: ...
A: ...

"""
[paste notes]
"""
```

### Summarize for revision
```
Summarize this into a one-page revision sheet: key terms with
definitions, main ideas, and anything likely to be on an exam.

"""
[paste text or attach file]
"""
```

### Hint, don't solve
```
I'm stuck on this problem. Don't give me the answer. Give me a hint
for the next step only.

[paste problem]
```

### Check my work
```
Here's my solution. Is it correct? If not, show me where I went wrong
but let me fix it myself.

Problem: [problem]
My solution: [your work]
```

### Feedback on an essay
```
Act as a strict but fair teacher. Give me feedback on this essay:
3 strengths, 3 most important things to improve, and a grade out of 10.
Don't rewrite it.

"""
[paste essay]
"""
```

### Study plan
```
I have [time] until my [exam]. Topics: [list]. I can study [hours] per day.
My weakest topics: [list]. Make a day-by-day study plan with review days
and one rest day per week.
```

### Language conversation partner
```
I'm learning [language], level [A1–C2]. Let's chat about [topic].
After each of my messages, first correct my mistakes briefly, then
continue the conversation. Keep your messages short and at my level.
```

### Explain the difference
```
What's the difference between [word/concept A] and [word/concept B]?
Give 5 examples of each so I can see the pattern.
```

### Learn anything fast
```
I want to learn the basics of [skill] in [time]. What are the 20% of
things that give 80% of the results? Give me a step-by-step plan and
the first thing to do today.
```

### Explain like a story
```
Explain [historical event / science concept] as a short, interesting
story, so it's easy to remember. Keep the facts accurate.
```
