# 📄 Working with files

You can give Claude files and images, not just text. This unlocks a lot of useful tricks.

## How to attach a file

- **Website / desktop:** click the **paperclip** or **+** button next to the message box, or just drag the file into the chat
- **Phone:** tap **+**, then choose a photo, take a new one, or pick a file

Common files that work: **PDF, Word documents, text files, spreadsheets (CSV, Excel), and images** (PNG, JPG, screenshots). There are size limits, so very large files may need to be split.

## 1. Summarize a long document

```
Summarize this PDF in 5 bullet points. Then list anything
I need to DO (deadlines, payments, signatures).
```

Better versions depend on what you need:
- `I'm a tenant. What in this rental contract could be bad for me?`
- `Explain this insurance policy in plain language. What is NOT covered?`
- `What are the 3 most important findings of this research paper?`

## 2. Ask questions about a document

After uploading, just chat about it:

- `On which page does it talk about cancellation?`
- `What does section 4.2 mean in simple words?`
- `Does this document say anything about refunds?`

💡 Ask: `Quote the exact sentence where it says that.` This makes it easy to check that Claude isn't making something up.

## 3. Understand a screenshot or photo

This one is underrated. Take a picture of almost anything and ask about it.

| Photo of... | Ask |
|-------------|-----|
| An error message on your computer | `What does this error mean and how do I fix it?` |
| A letter in a language you don't read | `Translate this and tell me if I need to do anything.` |
| A confusing bill | `Explain each line on this bill.` |
| A restaurant menu | `I don't eat pork. What can I order?` |
| A chart or graph | `What is this chart showing? What's the main takeaway?` |
| Your fridge | `What can I cook with this in 20 minutes?` |
| A math problem from your textbook | `Explain how to solve this step by step.` |

## 4. Work with a spreadsheet

Upload a CSV or Excel file:

```
This is my spending for the last 3 months. Group it by category,
tell me where most of my money goes, and suggest 3 realistic
ways to save.
```

More ideas:
- `Find any duplicate rows.`
- `Which product had the highest sales in March?`
- `Make a chart of this.` (Claude can often create charts you can see right in the chat.)
- `Write me an Excel formula that does X.`

⚠️ Double-check numbers in anything important. Ask: `Show me how you calculated that.`

## 5. Compare documents

Upload two files:

```
These are two job offers. Compare them in a table: salary,
benefits, vacation days, location, and anything unusual.
```

Or: `What changed between version 1 and version 2 of this contract?`

## 6. Turn one format into another

- `Turn this PDF table into a spreadsheet I can copy.`
- `Turn these meeting notes into a clean email for the team.`
- `Turn this long article into a 1-minute speech.`

## 🔒 Privacy reminder

Before uploading, ask yourself: *would I be OK if someone else saw this?* Remove or black out passwords, ID numbers, and bank details. See [Limits and safety](../start-here/05-limits-and-safety.md).
