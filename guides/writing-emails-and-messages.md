# ✉️ Writing emails and messages

This is the #1 thing most people use Claude for, and for good reason. It can turn a 20-minute "how do I say this?" into 2 minutes.

## 1. Write a new email from scratch

Tell Claude **who**, **why**, and **what tone**.

```
Write an email to my manager asking for Friday off next week.
Reason: my sister's wedding. I've already finished my part of
the current project. Tone: polite and short, not over-apologizing.
```

Then adjust:
- `Shorter.`
- `Less formal, we have a friendly relationship.`
- `Add a line offering to be reachable by phone if something urgent comes up.`

## 2. Reply to an email you received

**Paste the email you got.** This is the key step.

```
Here's an email from a client:

"""
[paste their email here]
"""

Write a reply. I want to say yes to the meeting, but on Thursday
instead of Wednesday. Keep it professional and friendly.
```

The `"""` marks just help Claude see where the pasted text starts and ends. They're optional but useful.

## 3. Fix your own draft

Already wrote something? Let Claude polish it instead of rewriting it.

```
Here's my draft. Fix grammar and make it sound more natural,
but keep my words and style as much as possible. Don't make it longer.

"""
[paste your draft]
"""
```

The phrase **"keep my words and style"** is important. Without it, Claude may rewrite everything and it won't sound like you anymore.

Bonus: ask `What did you change and why?` and you'll learn to write better yourself.

## 4. Change the tone

Same message, different feeling:

```
Rewrite this message in 3 versions:
1. More polite
2. More direct
3. More warm and friendly

"""
[your message]
"""
```

## 5. Handle awkward situations

Claude is great for the messages you've been avoiding.

```
I need to tell my friend I can't lend him money again. He's
borrowed 3 times and paid back once. I want to stay friends
but be clear that the answer is no. Write a short text message.
```

Other examples:
- Saying no to extra work at your job
- Asking someone to pay back money
- Complaining to a company and getting a refund
- Apologizing for a mistake
- Following up when nobody has replied

## 6. Write in another language

```
Write this message in formal German. I'll send it to a university
admissions office. Then show me the English translation underneath
so I know what it says.
```

Always ask for the translation back if you can't read the language, so you know what you're sending.

## ✅ Checklist before you hit send

- [ ] Did you read the whole thing? (Don't send anything you haven't read.)
- [ ] Are names, dates, and numbers correct?
- [ ] Does it sound like **you**? If not: `Make it sound more like a normal person, less like AI.`
- [ ] Did Claude add anything you didn't say, like promises or details? Remove them.
