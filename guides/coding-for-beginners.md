# 💻 Coding for beginners

You don't need to be a programmer to get value from code. Claude can write small tools for you, and teach you along the way if you want to learn.

## Start without installing anything

On [claude.ai](https://claude.ai), Claude can often build small things you can **see and use right in the chat**: a calculator, a simple game, a to-do list page, a chart. These show up in a panel next to the chat.

Try this:

```
Make me a simple web page where I can type my monthly expenses
and see a pie chart of where my money goes. Make it look clean
and modern.
```

Then just ask for changes:
- `Add a dark mode button.`
- `Let me add categories myself.`
- `Make the buttons bigger.`

You just made software without writing code. 🎉

## Ask for small automation scripts

Have a boring repeated task on your computer? Describe it.

```
I have a folder with 300 photos named like IMG_4821.jpg.
I want to rename them by the date they were taken, like
2024-05-12_001.jpg. I use a Mac and have never run code before.
Write a script and explain exactly how to run it, step by step.
```

The words **"I have never run code before"** make Claude explain every step: how to open the terminal, where to paste, and what to press.

⚠️ **Before running any script on your real files: make a backup copy first.** Test it on a few files in a separate folder.

## Learn to code with Claude as a tutor

```
I want to learn Python from zero. I learn best with small
practical projects. Teach me one concept at a time. After each
concept, give me a tiny exercise and wait for my code before
moving on. Don't give me the answer unless I ask.
```

Good beginner project ideas to ask for:
- A number guessing game
- A tip calculator
- A program that tells you the weather (using a free API)
- A to-do list that saves to a file
- A bot that sends you a daily reminder

## Fix errors

When something breaks, **copy the full error message** and paste it, along with your code:

```
I got this error when I ran my code:

"""
[paste the full error]
"""

Here's my code:

"""
[paste the code]
"""

What does it mean in simple words, and how do I fix it?
```

You can also take a screenshot of the error and attach it.

## Understand code you found

```
Explain this code line by line like I'm a complete beginner.
What does it do overall?

"""
[paste code]
"""
```

## Common beginner mistakes

| Mistake | Better |
|---------|--------|
| Asking for a huge app all at once | Start small, add one feature at a time |
| Not saying your computer (Mac/Windows/Linux) | Always say it, since instructions differ |
| Pasting only part of the error | Paste the whole thing |
| Running code you don't understand on important files | Ask "what will this do?" first, and back up |
| Copying code without reading it | Ask Claude to explain, so you learn |

## Ready for more?

When you're comfortable, Anthropic also makes **Claude Code**, a tool that works directly in your computer's terminal and can read and edit whole projects. That's a level 2 topic. Get comfortable with the basics here first.
