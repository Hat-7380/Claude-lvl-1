# Contributing

Thanks for wanting to help! This repo is for beginners, and **beginners are welcome to contribute too.** You don't need to be an expert.

## Easy ways to help

- **Fix a typo or unclear sentence.** Click the ✏️ pencil icon on any file on GitHub, make your change, and submit.
- **Share a prompt that works well for you.** Add it to the right file in [`prompts/`](prompts/).
- **Report something outdated.** Claude's features change. [Open an issue](../../issues) and tell us what's wrong.
- **Suggest a new guide.** Open an issue with your idea.
- **Translate.** Want this in Uzbek, Russian, or another language? Open an issue first so we can plan it together.

## Style rules

Keep it simple. The reader might be using AI for the very first time.

1. **Plain language.** Short sentences. No jargon. If you must use a technical word, explain it.
2. **Show, don't tell.** Every tip should have a real example the reader can copy.
3. **Prompts go in code blocks** so GitHub shows a copy button:
   ````
   ```
   Your prompt here with [placeholders in brackets]
   ```
   ````
4. **Use `[square brackets]`** for parts the reader should replace.
5. **Be honest about limits.** If something can be wrong or risky, say so.
6. **No hype.** Avoid "revolutionary", "game-changer", "10x your productivity".
7. **Don't promise specific features or prices.** They change. Say "check claude.ai for current plans" instead.

## Adding a prompt

Use this format:

````markdown
### Short title
```
The prompt text with [placeholders].
```
````

Before you add it, test it yourself in Claude at least once.

## Adding a guide

1. Create a new `.md` file in [`guides/`](guides/)
2. Follow the structure of an existing guide: short intro, numbered sections, example prompts, a safety note if relevant
3. Add a link to it in [`guides/README.md`](guides/README.md) and in the tree in the main [`README.md`](README.md)

## Be kind

Everyone was a beginner once. Be friendly in issues and pull requests.
