# Claude lvl 1

**Simple guides to help you get the most out of Claude, even if you've never used an AI assistant before.**

No jargon. No hype. Just clear steps, real examples, and prompts you can copy and use today.

---

## Who this is for

- You've heard of Claude (or ChatGPT) but never really used it
- You tried it once, got a so-so answer, and gave up
- You use it sometimes but feel like you're missing something
- You want to help a parent, friend, or coworker get started

If you already build apps with the Claude API, this repo is probably too basic for you, and that's fine.

## How to use this repo

Go in order if you're brand new. Jump around if you're not.

| Step | Section | What you'll get |
|------|---------|-----------------|
| 1 | [**Start here**](start-here/) | What Claude is, how to sign up, your first conversation, and how to ask good questions |
| 2 | [**Guides**](guides/) | Step-by-step walkthroughs for real tasks: emails, studying, documents, job search, and more |
| 3 | [**Prompts**](prompts/) | Copy-paste prompts, sorted by topic. Fill in the `[brackets]` and go |

## The 30-second version

If you read nothing else, read this:

1. **Talk to Claude like a smart coworker, not a search engine.** Full sentences work better than keywords.
2. **Give context.** Who you are, what it's for, who will read it. More context = better answer.
3. **Say what you want back.** "A short list", "one paragraph", "a table", "explain like I'm 12".
4. **Don't accept the first answer.** Reply with "shorter", "more casual", "give me 3 other options". That's normal, not a failure.
5. **Check important facts.** Claude can be confidently wrong. Double-check numbers, dates, names, and anything medical, legal, or financial.
