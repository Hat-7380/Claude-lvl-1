# 3. Your first conversation

Open [claude.ai](https://claude.ai), start a new chat, and follow along. Do it for real, since you'll learn faster than by reading.

## Round 1: Ask something simple

Type this:

```
I'm new to using AI assistants. What are 5 useful things I could
ask you to help with in my daily life?
```

Read the answer. Pick one idea that sounds useful to *you*.

## Round 2: Make it about you

Now ask about the idea you picked, and add some details about your life. For example:

```
Let's do the meal planning one. I live alone, I work 9 to 6,
I don't like cooking for more than 30 minutes, and I'm trying
to eat less sugar. Make me a plan for next week.
```

Notice how much more useful this answer is than if you'd just typed "meal plan". **That's the whole secret.** Details in, quality out.

## Round 3: Push back

Claude's first answer is a first draft. Reply to change it:

```
This is good but too complicated. Make it simpler. I want to
cook only 3 times a week and eat leftovers on other days.
```

Try other follow-ups too:

- `Make it a shopping list instead`
- `Put it in a table`
- `I don't eat fish, replace those meals`
- `Why did you choose these?`

You can keep going as long as you want. Claude remembers everything **in this chat**.

## Round 4: Ask it to explain something

Start a **new chat** and try:

```
Explain how credit cards work and why people end up in debt with them.
Explain it like I'm 16 and use a simple example with real numbers.
```

If any part is confusing, just ask: `I don't understand the part about interest, explain it differently.`

## What you just learned

1. ✅ Be specific about **your** situation
2. ✅ The first answer is a draft, so **ask for changes**
3. ✅ Tell it the **format** you want (list, table, short, simple)
4. ✅ Tell it the **level** you want (like I'm 16, for an expert, for my boss)
5. ✅ Each chat has its own memory, and a **new chat** starts fresh

## When to start a new chat

- When you switch to a different topic
- When the chat gets very long and answers start getting worse
- When Claude seems stuck on a wrong idea and keeps repeating it
