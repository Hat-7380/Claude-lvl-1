# 4. How to ask well

This is the most important page in the whole repo. Once you get this, everything else is easy.

## The formula

A great request usually has some of these parts. You don't need all of them every time.

| Part | Question it answers | Example |
|------|---------------------|---------|
| **Task** | What do you want? | "Write a message to my landlord" |
| **Context** | What's the situation? | "The heating has been broken for 5 days and I already asked once" |
| **Audience** | Who is it for? | "He's polite but slow to respond" |
| **Goal** | What should happen? | "I want it fixed this week without starting a fight" |
| **Format** | What should it look like? | "Short, under 100 words, friendly but firm" |
| **Examples** | What does "good" look like? | "Here's a message I liked before: ..." |

## Before and after

**❌ Weak:**
```
write email to landlord about heating
```

**✅ Strong:**
```
Write a message to my landlord. The heating in my apartment has been
broken for 5 days and I already asked him once, 3 days ago. He's
usually polite but slow to respond. I want it fixed this week without
starting a fight. Keep it under 100 words, friendly but firm.
```

The second one takes 30 seconds longer to type and saves you 5 minutes of editing.

## 8 tricks that work really well

### 1. Give it a role
```
You are an experienced HR manager. Review my CV and tell me
what you'd think if this landed on your desk.
```

### 2. Ask it to ask *you* questions first
```
I want to plan a trip to Istanbul. Before you make a plan,
ask me any questions you need to make it good.
```
This is great when you don't know what details matter.

### 3. Paste the actual thing
Don't describe the email you got. Paste it. Don't describe your essay. Paste it. Claude works much better with the real text.

### 4. Ask for options
```
Give me 3 different versions: one formal, one casual, one funny.
```

### 5. Say what you DON'T want
```
No bullet points. Don't use the words "delve" or "leverage".
Don't add a summary at the end.
```

### 6. Ask it to think step by step
For math, logic, or decisions:
```
Think through this step by step before giving your final answer.
```

### 7. Ask it to critique itself
```
Now read your answer as a strict teacher would. What's weak about it?
Then rewrite it fixing those problems.
```

### 8. Use your own language
Claude understands many languages. If you think better in Uzbek, Russian, Spanish, or anything else, write in it. You can also ask for the answer in a different language than you wrote in.

## When the answer is bad

Don't start over. Tell it what's wrong, specifically:

| Instead of... | Say... |
|---------------|--------|
| "No, that's wrong" | "The second point is wrong because X. Fix that part only." |
| "Make it better" | "Make it shorter and more casual. It sounds like a robot." |
| "Try again" | "This is too general. My situation is X, so focus on that." |

## A template you can reuse

Copy this into a note on your phone:

```
I need help with: [task]

Background: [your situation in 2-3 sentences]

It's for: [who will read/use it]

I want: [the result you're hoping for]

Format: [length, style, list/paragraph/table]
```
